# Briefs IA pour WiziShop

Des fichiers à donner à votre assistant IA (ChatGPT, Claude, Mistral…) pour qu'il vous guide pas à pas dans votre boutique WiziShop. Il vous pose les questions une par une, fait le travail dans votre boutique, et ne publie rien sans votre accord.

## Les briefs

| Fichier | À quoi il sert |
| --- | --- |
| [lancer-ma-boutique.md](lancer-ma-boutique.md) | Créer et lancer votre boutique de A à Z : ce que vous vendez, informations légales, paiement, livraison, produits, design, référencement, commande test, ouverture. |

## Comment l'utiliser

1. **Branchez WiziShop à votre IA** : dans votre administration WiziShop, rubrique **IA**, puis **Brancher mon IA**. Ça prend une minute.
2. **Téléchargez le brief** : ouvrez le fichier ci-dessus, puis cliquez sur l'icône « Download raw file ».
3. **Ouvrez une nouvelle conversation** avec WiziShop activé, glissez-y le fichier et envoyez-le.

Votre assistant fait l'état des lieux de votre boutique, puis vous pose sa première question.

Pas encore de boutique ? [Démarrez gratuitement sur wizishop.fr](https://www.wizishop.fr/).
